### Kept as claude-reflect, on purpose

- **The hidden AGENTS.md tag** (`<!-- Auto-generated by claude-reflect ...` and `<!-- End claude-reflect section -->`). Reason: the plugin finds the section it wrote inside AGENTS.md files by this tag; renaming it would orphan every section the original already wrote.

- **Command names** (`reflect`, `reflect-skills`, `skip-reflect`, `view-queue`). Reason: `/reflect` keeps working; the long names become `/beas-reflect:reflect` and so on.
